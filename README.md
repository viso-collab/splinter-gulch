# Splinter Gulch

A top-down western smashing game in a single HTML file.

Steer an auto-swinging hammer over roaming piggy banks, clear timed days by smashing enough piggies, find chests and equip one ability at a time.

## Play

Open `index.html` in a browser, or play it on GitHub Pages:
https://viso-collab.github.io/splinter-gulch/

Progress is saved in your browser (localStorage).

## How it works

- **Days:** each day has a time limit and a number of piggies to smash. Clear it to move on, or upgrade and try again.
- **Piggies:** new piggy types show up on later days. Each has its own trick (dashing away, exploding, going on a rampage, repairing itself).
- **Chests:** smashed piggies can drop chests with abilities in five rarities (Common to Mythic). Duplicates level an ability up to 5.
- **Store:** upgrade swing speed, hammer damage, day length and chest chance.
